# react_angular

A comprehensive hands-on journey from **Beginner to Advanced** comparing and mastering **React** and **Angular** side-by-side using a shared backend.

## 📁 Repository Structure

```
react_angular/
├── backend/          # Shared pure backend (Node.js + Express REST API)
├── react-app/        # React frontend (Vite + React)
└── angular-app/      # Angular frontend
```

## 🗺️ Learning Roadmap

### Phase 1: React Mastery (Beginner to Advanced)
1. **Module 1: Foundations** — Project setup, JSX, Components, Props, and State (`useState`).
2. **Module 2: Interactivity & Forms** — Event handling, controlled inputs, validation, and lists/keys.
3. **Module 3: Side Effects & Backend Integration** — `useEffect`, fetching data from the backend, loading/error states.
4. **Module 4: Routing & Architecture** — React Router, page layouts, reusable design system.
5. **Module 5: Advanced State & Performance** — Custom hooks, Context API / Zustand, optimization (`useMemo`, `useCallback`).

### Phase 2: Angular Mastery (Bridging the Concepts)
- Rebuilding the exact same application using Angular concepts (Components, Directives, Signals/RxJS, Services, Dependency Injection, Angular Router, NgRx/Signals Store).
